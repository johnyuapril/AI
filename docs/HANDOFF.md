- 대본: 불러오기(PDF·HWP·HWPX·DOCX·TXT·Fountain), 한국식 위아래/나란히/할리우드 양식, 엔터·Tab 자동 줄 종류, `. @ ( > ! /` 앞글자 단축키, 화면 아래 줄 종류 버튼, 인물 이름 일괄 바꾸기, 씬/인물/장소 목록
- 신 리스트: 씬 표, 컷 자동 나누기(문맥 규칙), 끌어서 합치기, ✂ 나누기, 샷·앵글·움직임·인물 고르기, CSV
- 장면 묘사: 외부 AI용 복사 → 답 붙여넣기 → 설정표와 컷 묘사 자동 채움, 바로잡기, 문서 내보내기
- 그림: 컷/씬/마스터 프롬프트 복사, 그림체와 화풍 참고 그림, 받은 그림 넣기(갤러리, 붙여넣기, 여러 장 한꺼번에. 파일 이름에 1-3 같은 컷 번호가 있으면 그 컷에 들어감)
- 스토리보드: 기본 콘티(A4 세로 5컷), 6컷 모아보기(가로), 샷 리스트, 칸 직접 고치기, S Pen으로 직접 그리기와 덧그리기, PDF 저장
- 분석: 대사 분량, 씬별 등장인물, 장소 낮/밤, CSV
- 백업: 작품별 .sbk, 전체 백업 zip, 불러오기

## APK 빌드

- 저장소 비밀값 `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`가 있어야 한다.
