- 대본: 불러오기(PDF·HWP·HWPX·DOCX·TXT·Fountain), 한국식 위아래/나란히/할리우드 양식, 엔터·Tab 자동 줄 종류, `. @ ( > ! /` 앞글자 단축키, 화면 아래 줄 종류 버튼, 인물 이름 일괄 바꾸기, 씬/인물/장소 목록
- 신 리스트: 씬 표, 컷 자동 나누기(문맥 규칙), 끌어서 합치기, ✂ 나누기, 샷·앵글·움직임·인물 고르기, CSV
- 장면 묘사: 외부 AI용 복사 → 답 붙여넣기 → 설정표와 컷 묘사 자동 채움, 바로잡기, 문서 내보내기
- 그림: 컷/씬/마스터 프롬프트 복사, 그림체와 화풍 참고 그림, 받은 그림 넣기(갤러리, 붙여넣기, 여러 장 한꺼번에. 파일 이름에 1-3 같은 컷 번호가 있으면 그 컷에 들어감)
- 스토리보드: 기본 콘티(A4 세로 5컷), 6컷 모아보기(가로), 샷 리스트, 칸 직접 고치기, S Pen으로 직접 그리기와 덧그리기, PDF 저장
- 분석: 대사 분량, 씬별 등장인물, 장소 낮/밤, CSV
- 백업: 작품별 .sbk, 전체 백업 zip, 불러오기

## 최근 변경 (2026-11-01 오후)
- 한글(HWP) 불러오기 고침: 본문 섹션을 못 찾던 문제. 파일 확장자 대신 파일 내용으로 형식 판단. 배포용/암호 HWP는 안내 메시지.
- PDF 한글 글꼴(CID) 읽기: pdfjs cMap/표준 글꼴을 빌드 때 public/pdfjs 로 복사(prebuild).
- 표지(첫 씬 앞 제목·날짜)는 지문으로.
- 버전 표시와 업데이트: 홈 화면에 버전, "업데이트 확인" 버튼. 새 버전이 있으면 앱 안에서 APK를 받아 설치 화면을 띄움 (android AppUpdaterPlugin.java, src/update.ts). 저장소가 공개여야 동작(비공개면 다운로드 페이지를 엶).
- 저장소: 사용자가 AI2를 AI로 이름을 바꾸고 공개로 전환함. 이제 johnyuapril/AI 하나만 씀. 앱 업데이트도 AI의 릴리스를 봄.

- 구글 자동 저장: 사용자의 구글 앱스 스크립트 웹 앱(코드: tablet-app/src/google-sync.gs.txt, 앱의 "구글 연결" 창에서 비밀 키가 채워진 채로 복사)에 POST. 드라이브 "시나리오 작업실" 폴더에 대본 문서, 장면 묘사 문서, 신 리스트 스프레드시트(신 리스트/컷 리스트/장면 묘사 탭)를 만들고 덮어씀. 고친 뒤 1분, 작품을 닫거나 앱이 뒤로 갈 때 자동 업로드. 사용자가 연결까지 성공함. 코드 v2: Paragraph.setText 가 void 를 돌려줘서 이어 쓰기(체이닝)하다 깨지던 문제 고침. 코드 v3: 시트를 앱의 신 리스트처럼 (씬 줄 + 접힌 컷 줄 묶음, 열 너비·색), 장면 묘사 탭도 같은 모양, 컷 리스트 탭은 없앰. 앱은 응답의 version 이 CODE_VERSION 보다 낮으면 "다시 붙여넣기" 안내.
