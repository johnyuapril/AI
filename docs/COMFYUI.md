# ComfyUI로 컷 그림 바로 그리기 (PC: RTX 3080 10GB 기준)

앱의 그림 탭에서 버튼 한 번에 내 PC의 ComfyUI가 컷 그림을 그려서 그 컷에 넣는다.
윈도우용 앱이 가장 쉽고, 태블릿도 같은 와이파이면 PC에 그리게 할 수 있다.

## 1. ComfyUI 설치 (한 번만)
1. https://www.comfy.org/download 에서 **Windows (NVIDIA)** 용 ComfyUI Desktop을 받아 설치한다.
2. 처음 켜면 설치 위치를 묻는다. 모델 파일이 커서 여유 공간이 30GB 이상인 드라이브를 고른다.

## 2. 그림 모델 받기 (한 번만)
- 처음엔 **SDXL** 모델 하나면 된다. 10GB 그래픽카드에서 한 장에 10~20초 정도.
- ComfyUI 왼쪽 **템플릿(Templates)** → SDXL 기본 템플릿을 열면 빠진 모델을 받으라는 창이 뜬다 → 다운로드.
  (직접 받을 때: `sd_xl_base_1.0.safetensors` 를 ComfyUI 폴더의 `models/checkpoints` 에 넣는다.)
- 콘티 그림체가 더 잘 맞는 SDXL 계열 모델(예: Juggernaut XL)로 바꿔도 된다. 같은 폴더에 넣으면 앱의 "모델" 목록에 나온다.

## 3. 앱과 연결
1. ComfyUI를 켜 둔다.
2. 윈도우용 앱 → 작품 열기 → **그림** 탭 → 맨 위 **"ComfyUI로 바로 그리기"** → **연결 확인**.
   - ComfyUI Desktop은 주소가 `http://127.0.0.1:8000`, 직접 설치판은 `:8188`. 앱이 둘 다 찾아본다.
3. **모델**에서 받은 모델을 고른다.

## 4. 그리기
1. 씬마다 **영문 요청 복사** → ChatGPT에 붙여 넣기 → 답을 복사 → **영문 답 넣기**.
   (그림 모델은 한국어를 못 읽어서, 컷마다 영어 프롬프트가 필요하다. 인물 생김새를 모든 컷에서 같은 말로 쓰게 한다.)
2. **ComfyUI로 씬 그리기**: 그림 없는 컷을 차례로 그린다. 다시 누르면 멈춘다.
3. 컷 하나만 다시 그리려면 그 컷의 **ComfyUI** 버튼.
4. 그림체(영어)와 빼고 싶은 것(영어)은 설정 칸에서 고친다. 기본값은 마커펜 러프 흑백 콘티.

## 5. 태블릿에서 PC로 그리기 (선택)
- ComfyUI 설정(Settings) → Server Config: 들어오는 주소(Host/listen)를 `0.0.0.0`, **CORS 헤더 허용**을 `*` 로.
  직접 설치판이면 실행 옵션에 `--listen 0.0.0.0 --enable-cors-header "*"`.
- 윈도우 방화벽이 물으면 "허용".
- 태블릿 앱 주소 칸에 PC 주소(예: `http://192.168.0.10:8000`). PC 주소는 PC에서 `ipconfig` → IPv4 주소.

## 6. 인물 얼굴 맞추기 (다음 단계)
- 기본 워크플로는 글만 보고 그려서 컷마다 얼굴이 조금씩 다르다.
- 캐릭터 시트를 참고 그림으로 쓰는 워크플로(IP-Adapter, Flux Kontext 등)를 ComfyUI에서 만든 뒤:
  프롬프트 칸에 `{{prompt}}`, 네거티브 칸에 `{{negative}}`, 참고 그림 Load Image 노드 제목을 `ref` 로 바꾸고
  **Export (API)** 로 저장 → 앱 "내 워크플로 넣기". 그림 탭 "인물 캐릭터 시트"에 시트 그림을 넣어 두면 컷의 첫 인물 시트를 보낸다.
- 나중엔 인물 LoRA 학습도 가능.
